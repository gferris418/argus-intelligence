# Synthesized ARGUS Intelligence

This directory stores synthesized intelligence derived from external/public/internal sources without storing the original source documents.

Allowed examples:
- opportunity briefs;
- project/funding summaries;
- procurement package summaries;
- buyer/end-user/PE analysis;
- requirement extraction;
- reconciliation notes;
- competitive/installed-base synthesis;
- Research Frontier notes;
- decision rationale and next-action records.

Preferred formats: Markdown and JSON.

Every synthesis should cite or reference its source system/locator and `as_of` date. Raw tender PDFs, Word files, scanned notices, email payloads, bid documents, or archive bundles are prohibited.
