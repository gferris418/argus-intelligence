# ARGUS Intelligence v2.0.0 Release Decision

**Date:** 2026-10-19  
**Channel:** stable  
**Status:** RELEASED  
**Predecessor:** 2.0.0-rc.5 at `6f2136ff4f065dcab077fb58a0432c2a9d4c5389`  
**ATLAS baseline:** 2.0.0 at `a533d092fb35f5c048a96f46c0201d5ce37871c7`

## Compatibility basis

ARGUS rc.5 contract tests passed against the ATLAS rc.12 runtime/contract baseline. ATLAS 2.0.0 stable is a release/governance promotion of that baseline: the rc.12→2.0.0 diff changes release metadata, documentation, migration release-blocking policy, version-bound integration text, and tests, but does not modify the ATLAS runtime, domain-context handoff, approval, or verification contracts.

ARGUS 2.0.0 therefore repins its upstream identity to the exact ATLAS stable commit while preserving all six validated source-contract hashes.

## Runtime receipt compatibility

The product release is ARGUS `2.0.0`. The synchronization receipt implementation remains `2.0.0-rc.5` for backward-compatible wire behavior because that is the tested runtime revision from the release-candidate baseline. A future protocol revision may advance independently under explicit compatibility governance.

## Operator release-risk acceptance

The repository owner explicitly directed final release without waiting for the credentialed private-repository remote E2E. The previous attempted remote E2E did not enter compatibility logic because `ATLAS_READ_TOKEN` was unavailable at private ATLAS checkout. This remains a disclosed post-release verification item and is not represented as passed.

## Invariants retained

- ATLAS owns the execution spine, plan, approvals, verification, persistence, and final delivery.
- ARGUS remains a nested specialist government/public-sector opportunity-intelligence method.
- Domain Context Handoff remains v1.1.
- The ATLAS activation contract remains unchanged.
- The six pinned ATLAS source-contract hashes remain unchanged from the tested rc.5 compatibility baseline.
- No raw tender/source documents or secrets are introduced into the ARGUS canonical Git store.
