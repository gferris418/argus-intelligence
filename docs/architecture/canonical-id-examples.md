# Canonical ID Examples

Examples only; live IDs are allocated by the operational database.

- `POL-BD-000001` — policy
- `STR-BD-000001` — strategy/master plan
- `PRG-BD-000001` — programme
- `PRJ-BD-000001` — project
- `REQ-BD-000001` — requirement
- `PLN-BD-000001` — procurement plan
- `PKG-BD-000001` — procurement package
- `PROC-BD-000001` — procurement process
- `TND-BD-000001` — solicitation/tender
- `LOT-BD-000001` — lot
- `ITM-BD-000001` — item
- `ENT-GLB-000001` — organization/entity when not country-scoped
- `PRD-GLB-000001` — product/solution
- `AWD-BD-000001` — award
- `CTR-BD-000001` — contract

Existing ARGUS IDs already in production history remain valid legacy identities and are attached as aliases/external identifiers during migration; they are not silently renumbered.
